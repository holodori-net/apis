# Contributing

Install the pinned dependencies and run the complete validation suite before
submitting changes:

```sh
pnpm install
pnpm validate
```

## Protobuf contracts

`proto/descriptor-set.pb` is the source of truth for generated protobuf
messages and schemas. `proto/descriptor-set.source.json` records the upstream
repository, descriptor commit, app version, and checksum. To sync from a
checked-out `android-protos` repository, regenerate and verify the output:

```sh
pnpm protos:sync --upstream ../android-protos
pnpm protos:generate
pnpm protos:check
```

The `Sync protobuf contracts` workflow runs when `android-protos` publishes a
new descriptor. It also supports manual runs with an optional `source_ref`.

Generated files under `src/protos/gen/` must not be edited directly. Add a new
API descriptor root to `scripts/generate-protos.mjs` when implementing a domain
that is not already generated.

## API documentation

Public service classes and methods require concise JSDoc summaries. Add an
`@rpc` tag with the full gRPC method path and use `@remarks` for account-specific
fields, state changes, or usage constraints.

Generate the API reference after changing a public method or its documentation:

```sh
pnpm docs:api
```

`docs/api-reference.md` is generated by `scripts/generate-api-docs.mjs` and
must not be edited directly. The generator fails when a public service class or
method has no JSDoc summary.

## Releases

Use Conventional Commits. Merges to `main` automatically release changes that
affect the package: `feat` increments the minor version; `fix`, `perf`,
`refactor`, and `revert` increment the patch version; a breaking change
increments the major version. Documentation, test, CI, build, style, and chore
commits do not release by themselves.

The release workflow updates `package.json` and `CHANGELOG.md`, creates the
release commit and tag, publishes the GitHub Release, and publishes the package.
Do not edit release versions, changelog entries, or tags manually. From a clean
`main` checkout with its upstream configured, preview the next release without
changing the repository:

```sh
pnpm release:dry-run
```
